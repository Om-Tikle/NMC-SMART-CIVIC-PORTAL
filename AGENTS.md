# NMC Smart Civic Complaint & Resolution Portal

## Project goal
Build a civic complaint and resolution portal in small, reviewable phases.

## Planned zero-cost-first architecture
- Mobile app: React Native with Expo
- Web app: React.js
- Backend: Node.js with Express
- Database: MongoDB Atlas Free
- Machine learning: Python with PyTorch
- Security: JWT, IMA, and role-based access control (RBAC)
- Maps: OpenStreetMap

## Working rules
- Do not build the entire application at once.
- Work one approved phase at a time.
- Do not install packages or generate application code unless the current task explicitly asks for it.
- Do not introduce paid services or major architecture changes without approval.
- Never commit passwords, API keys, tokens, connection strings, or `.env` files.
- Keep documentation updated as each phase is completed.
- Prefer simple, maintainable, accessible solutions.
